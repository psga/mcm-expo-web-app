# mcm-expo-web-app
Este repositorio contiene el prototipo funcional del aplicativo web interactivo diseñado para la corporación **MCM (Maratón Ciudad de Medellín)**. 


## como usar

instala streamlit 
`pip install -r requeriments.txt`
  
dentro de `/MCM`

 `(.venv) [pablo@pablo mcm-expo-web-app]$ streamlit run Inicio.py`
